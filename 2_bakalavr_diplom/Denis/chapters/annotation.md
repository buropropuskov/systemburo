# АННОТАЦИЯ

Выпускная квалификационная работа посвящена разработке плагина для системы дистанционного обучения Moodle, автоматически сравнивающего студенческие работы на предмет заимствований в рамках одного задания. Плагин принимает файлы в форматах DOCX, PDF, TXT, ODT, XLSX и исходный код на Python, Java, C++, PHP, выполняет попарное сопоставление и формирует отчёт с оценкой сходства для преподавателя.

В работе выполнен анализ инструментов проверки уникальности (Turnitin, Антиплагиат, MOSS, JPlag), выявлены их ограничения в LMS-среде и сформулированы требования к плагину. Построена модель предметной области: акторы, диаграммы вариантов использования, BPMN-процессы «как есть» и «как будет». Спроектирована архитектура и схема базы данных, обоснован выбор метода шинглов с коэффициентом Жаккара для текста и алгоритма Winnowing для исходного кода. Плагин реализован на PHP 8.1, покрыт тестами PHPUnit; по итогам экспериментальной оценки подтверждено снижение трудозатрат преподавателя.
