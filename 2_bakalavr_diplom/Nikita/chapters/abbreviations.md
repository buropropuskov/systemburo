# СПИСОК ИСПОЛЬЗУЕМЫХ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ

**ТО** — техническое обслуживание; комплекс работ по поддержанию работоспособности оборудования.

**ТОиР** — техническое обслуживание и ремонт; совокупность процессов поддержания и восстановления работоспособности оборудования.

**ППР** — планово-предупредительный ремонт; ремонт, выполняемый по фиксированному расписанию до возникновения отказа.

**CMMS** (Computerized Maintenance Management System) — компьютеризированная система управления техническим обслуживанием и ремонтом.

**EAM** (Enterprise Asset Management) — управление основными фондами предприятия; класс информационных систем, расширяющий CMMS управлением жизненным циклом активов и финансовым учётом.

**CBM** (Condition-Based Maintenance) — обслуживание по фактическому состоянию оборудования.

**PdM** (Predictive Maintenance) — предиктивное обслуживание, основанное на прогнозировании отказов с использованием моделей машинного обучения.

**MTTR** (Mean Time To Repair) — среднее время устранения отказа; ключевая метрика надёжности по ГОСТ 27.002-2015.

**MTBF** (Mean Time Between Failures) — среднее время между двумя последовательными отказами оборудования.

**MoSCoW** — метод приоритизации требований: Must have, Should have, Could have, Won't have.

**REST** (Representational State Transfer) — архитектурный стиль распределённых систем.

**REST API** (Representational State Transfer Application Programming Interface) — программный интерфейс на основе REST.

**JWT** (JSON Web Token) — открытый стандарт компактных токенов аутентификации.

**RBAC** (Role-Based Access Control) — модель управления доступом на основе ролей.

**HMAC** (Hash-based Message Authentication Code) — код проверки подлинности сообщения с использованием хеш-функции.

**SPA** (Single Page Application) — одностраничное веб-приложение, динамически перезагружающее содержимое без полной перезагрузки страницы.

**ORM** (Object-Relational Mapping) — объектно-реляционное отображение; технология связывания объектов программы с записями базы данных.

**JSON** (JavaScript Object Notation) — текстовый формат обмена структурированными данными.

**JSONB** — бинарное представление JSON в PostgreSQL, поддерживающее индексацию.

**ACID** (Atomicity, Consistency, Isolation, Durability) — набор гарантий, обеспечиваемых транзакционными базами данных.

**ER** (Entity-Relationship) — модель «сущность-связь», используемая при проектировании баз данных.

**BPMN** (Business Process Model and Notation) — стандартизированная нотация для моделирования бизнес-процессов.

**UML** (Unified Modeling Language) — унифицированный язык графического описания программных систем.

**GIL** (Global Interpreter Lock) — глобальная блокировка интерпретатора, ограничивающая параллельное выполнение байт-кода в Python.

**SaaS** (Software as a Service) — модель распространения программного обеспечения по подписке через облачную платформу.

**IoT** (Internet of Things) — Интернет вещей; концепция сети физических устройств с возможностью обмена данными.

**ML** (Machine Learning) — машинное обучение.

**ИИ** — искусственный интеллект.

**СУБД** — система управления базами данных.

**ОС** — операционная система.

**ОГМ** — отдел главного механика.

**ЧПУ** — числовое программное управление.

**QR-код** (Quick Response code) — двухмерный матричный штрих-код, считываемый камерой устройства.

**CI/CD** (Continuous Integration / Continuous Delivery) — непрерывная интеграция и непрерывная поставка программного обеспечения.

**HTTP** (HyperText Transfer Protocol) — прикладной протокол передачи гипертекста.

**HTTPS** — HTTP поверх защищённого протокола TLS.
