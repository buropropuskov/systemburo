# АННОТАЦИЯ

Выпускная квалификационная работа посвящена разработке веб-приложения для управления техническим обслуживанием и ремонтом оборудования предприятия. Проведён анализ предметной области ТОиР, выполнен сравнительный обзор существующих CMMS-систем, спроектирована архитектура приложения и структура базы данных. Серверная часть реализована на Go (Echo, GORM), клиентская на Vue 3 (Composition API, Pinia). Развёртывание выполнено в Docker-контейнерах. Проведено модульное, интеграционное и сквозное тестирование.

Общий объём работы составляет 72 страницы основного текста, 7 страниц приложений. Работа содержит 13 рисунков, 7 таблиц, 7 листингов, 2 приложения. Список использованных источников включает 30 наименований.

Ключевые слова: техническое обслуживание и ремонт, ТОиР, CMMS, веб-приложение, Go, Vue, REST API, PostgreSQL, Docker, управление оборудованием.
