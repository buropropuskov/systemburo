# Руководство пользователя сервиса Dockee

Dockee — веб-приложение для автоматизированного анализа юридических документов. Пользователь загружает файл, ИИ-модель подсвечивает риски и даёт пояснения, результат можно выгрузить PDF-отчётом.

## 1. Начало работы

### 1.1 Регистрация

1. Открыть главную страницу сервиса в браузере.
2. В шапке нажать «Войти» → «Зарегистрироваться».
3. Ввести email и пароль (от 8 символов, буквы + цифры).
4. Принять условия и нажать «Создать аккаунт».
5. Перейти в почтовый ящик, открыть письмо от Dockee и нажать ссылку подтверждения.
6. После подтверждения откроется экран выбора тарифа.

Если письмо не пришло в течение 2 минут, проверить «Спам» или нажать «Отправить повторно» на странице ожидания подтверждения.

### 1.2 Выбор тарифа

Доступны три плана:

- **Тестовая** — бесплатно, 3 проверки в сутки, без экспорта PDF.
- **Базовая** — 15 проверок в сутки, экспорт PDF, ИИ-помощник.
- **Продвинутая** — безлимитные проверки, приоритетная очередь, аналитика по контрагентам, расширенная архивация.

При выборе платного тарифа открывается форма оплаты. После успешной оплаты пользователь попадает на рабочий стол сервиса.

### 1.3 Вход в аккаунт

1. На главной странице нажать «Войти».
2. Ввести email и пароль, нажать «Войти».
3. При включённой двухфакторной аутентификации ввести шестизначный код из приложения-аутентификатора.

Восстановление пароля — по кнопке «Забыли пароль?» на форме входа: письмо со ссылкой сброса приходит на email.

## 2. Главная страница (анализ документа)

### 2.1 Загрузка документа

Поддерживаемые форматы: **PDF, DOC, DOCX, TXT**. Максимальный размер одного файла — **20 МБ**.

Способы загрузки:

- Нажать на кнопку «Загрузить документ» и выбрать файл в проводнике.
- Перетащить файл в область drag-and-drop в центре экрана.
- Загрузить сразу несколько файлов одним пакетом (до 5 одновременно).

После загрузки появляется список файлов с размером и иконкой формата. При нажатии на иконку корзины файл удаляется из очереди.

### 2.2 Запуск анализа

1. Отметить чекбокс согласия на обработку загруженных данных.
2. Нажать «Проверить документы».
3. Появляется индикатор прогресса: приём файла, извлечение текста, анализ ИИ, подготовка отчёта. Обычно весь процесс занимает 10–30 секунд.

Если анализ не завершается более 60 секунд, отображается сообщение об ошибке с кнопкой «Повторить».

### 2.3 Работа с результатами

Результат анализа состоит из четырёх блоков:

- **Сводка документа**: название, формат, число страниц, дата загрузки.
- **Текст документа**: оригинальный текст с подсветкой фрагментов. Красный маркер — критический риск, жёлтый — сомнительная формулировка, зелёный — пункт принят без замечаний.
- **Панель замечаний** (справа): список рисков с краткими пояснениями от ИИ. Клик по пункту перематывает к соответствующему фрагменту документа.
- **ИИ-помощник** (выдвижная панель справа): можно задать уточняющий вопрос по документу на естественном языке.

### 2.4 Действия с замечаниями

Каждое замечание в правой панели имеет три действия:

- **Принять** — пользователь согласен, риск подтверждён.
- **Отклонить** — риск не актуален для данного документа.
- **Заметка** — текстовое поле для собственного комментария к пункту.

Установленные статусы сохраняются автоматически и отражаются в итоговом PDF-отчёте.

### 2.5 Экспорт отчёта

Кнопка «Скачать отчёт» в правом верхнем углу формирует PDF со следующей структурой:

1. Титульный лист (название документа, дата анализа, пользователь).
2. Сводка рисков (количество по уровням критичности).
3. Полный текст документа с цветовой подсветкой.
4. Развёрнутый список замечаний с пояснениями ИИ и пользовательскими заметками.

Файл сохраняется в стандартную папку загрузок браузера.

## 3. Раздел «Документы»

Файловое хранилище загруженных документов. Доступно из левого меню.

Возможности:

- Поиск по названию через строку в шапке раздела.
- Сортировка по имени, дате, размеру, статусу проверки.
- Создание папок и перетаскивание файлов между ними.
- Предустановленные папки: «Работа», «Контракты», «Отчёты». Пользователь может переименовывать их и создавать свои.
- Контекстное меню (правая кнопка мыши по файлу): «Открыть», «Проверить заново», «Переименовать», «Скачать», «Архивировать», «Удалить».
- Массовые операции: отметить несколько файлов чекбоксами и применить действие сразу ко всем.
- Индикатор занятого места: «использовано 103 МБ из 2 ГБ».
- Корзина: удалённые файлы хранятся 30 дней, их можно восстановить или стереть безвозвратно.

## 4. Раздел «Аналитика»

Сводные показатели по всем проанализированным документам пользователя за выбранный период.

### 4.1 Фильтры

В верхней части страницы:

- **Период**: за неделю, месяц, квартал, произвольный диапазон дат.
- **Тип файлов**: все, договоры, счета, акты, другое.
- **Контрагент**: выпадающий список из всех упомянутых в документах.

Фильтры применяются к обоим блокам страницы: сводным карточкам и детализации.

### 4.2 Сводные карточки

Пять показателей за период:

- проверено документов;
- средний процент соответствия стандартам;
- число уникальных контрагентов;
- выявлено рисков (с разбивкой по критичности);
- процент отклонённых замечаний (оценка качества ИИ).

### 4.3 Детализация по контрагентам

Таблица: контрагент, количество документов, средний балл качества, число рисков, рейтинг доверия. Столбец «Решение» позволяет отметить контрагента как «Доверять» или «Не доверять» — пометка отображается при последующих анализах документов этого контрагента.

Кнопка «Скачать отчёт» над таблицей формирует Excel-файл с полной детализацией за период.

## 5. Личный кабинет

Раздел «Аккаунт» в левом меню. Содержит три вкладки.

### 5.1 Общие настройки

- **Язык интерфейса**: русский, английский.
- **Формат даты и времени**: ДД.ММ.ГГГГ или MM/DD/YYYY.
- **Масштаб интерфейса**: 90 %, 100 %, 110 %, 125 %.
- **Всплывающие подсказки**: включены / выключены.
- **Цветовая схема**: светлая, тёмная, автоматически по системе.

### 5.2 Анализ и промпты

- **Режим анализа**: базовый (риски только высокой критичности) или расширенный (включая сомнительные формулировки).
- **Рекомендации**: показывать / скрывать предложения ИИ по улучшению формулировок.
- **Тепловая карта**: визуализация плотности рисков по страницам.
- **Пользовательский промпт**: текстовое поле для собственной инструкции ИИ. Подставляется в системный prompt при анализе. Максимум 500 символов.

### 5.3 Подписка и платежи

- Текущий тариф, дата следующего списания, способ оплаты.
- История платежей: дата, сумма, статус, ссылка на квитанцию.
- Кнопка «Пополнить баланс» — для оплаты дополнительных проверок сверх тарифа.
- Кнопка «Сменить тариф» — переход к форме смены плана (переход на более высокий вступает в силу сразу, на более низкий — по окончании оплаченного периода).
- **Устройства**: список авторизованных сессий с возможностью завершить любую из них.

## 6. ИИ-помощник

Выдвижная панель справа, доступна на странице анализа документа и в разделе «Документы» при открытом файле.

Возможности:

- Задавать вопросы по загруженному документу («Какие штрафные санкции предусмотрены?», «Какой срок действия договора?»).
- Получать цитаты из документа в ответе.
- Просить перефразировать замечания простым языком.
- Копировать ответ одной кнопкой в буфер обмена.

Ограничения:

- Не обрабатывает документы, защищённые паролем.
- Не даёт юридических консультаций вне контекста загруженного документа.
- История переписки сохраняется только в течение текущей сессии.

## 7. Частые проблемы

| Ситуация | Решение |
|---|---|
| Документ не загружается | Проверить формат (PDF/DOC/DOCX/TXT) и размер (до 20 МБ). Убедиться, что файл не защищён паролем |
| Анализ завис на 100 % | Обновить страницу (F5). Если результат уже сохранён, откроется готовый отчёт |
| Нет кнопки «Скачать отчёт» | Функция доступна на тарифах «Базовая» и «Продвинутая» |
| Не приходит письмо подтверждения | Проверить папку «Спам», запросить повторно на странице ожидания |
| Подсветка рисков пропала | Отключены цветовые метки в настройках анализа — включить в разделе «Аккаунт» → «Анализ» |
| ИИ-помощник не отвечает | Проверить интернет-соединение и квоту проверок (для тарифа «Базовая» — 15 в сутки) |

## 8. Горячие клавиши

- `Ctrl + U` — открыть диалог загрузки документа.
- `Ctrl + F` — поиск по документу на странице анализа.
- `Ctrl + S` — скачать PDF-отчёт (с открытой страницы анализа).
- `J / K` — следующее / предыдущее замечание в правой панели.
- `Esc` — закрыть модальное окно или выдвижную панель.

## 9. Поддержка

- Встроенная форма обратной связи: иконка «?» в правом нижнем углу любой страницы.
- Email: support@dockee.ru.
- Время ответа: до 24 часов для «Базовой», до 4 часов для «Продвинутой».
