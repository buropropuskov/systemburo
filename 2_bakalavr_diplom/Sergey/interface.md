# Краткое описание пользовательского интерфейса сервиса Dokkee

## 1. Лендинг (посадочная страница)

**Что можно делать:**
- Ознакомиться с преимуществами сервиса (блоки «Сокращение времени», «Оптимизация работы», «Точность алгоритмов», «Экономия ресурсов»)
- Посмотреть статистику (активные клиенты, партнеры, проверенные документы)
- Выбрать тариф (Тестовая, Базовая, Продвинутая) и нажать «Выбрать план»
- Изучить этапы работы: загрузка документов → анализ файлов → получение отчёта
- Посмотреть информацию о команде разработчиков
- Прочитать FAQ (раскрывающиеся вопросы и ответы)
- Заполнить форму обратной связи (имя, телефон, email, тема обращения)
- Перейти к регистрации/входу через кнопку «Войти» в шапке

## 2. Главная страница (работа с документом)

**Что можно делать:**
- Загружать один или несколько документов (через клик или перетаскивание) в форматах PDF, DOC, DOCX
- Просматривать список успешно загруженных файлов с указанием размера
- Запускать проверку и анализ документов
- Получать результат анализа: общая информация о документе (название, формат, страницы, дата), ключевые замечания с цветовыми метками (красные — критические ошибки, жёлтые — сомнительные моменты)
- Читать подробности («Читать далее...»)
- Скачивать итоговый отчёт (кнопка «Скачать отчёт»)
- Взаимодействовать с выдвигающимся ИИ-помощником (справа) – задавать вопросы, получать ответы по документу
- Давать согласие на обработку персональных данных (чекбокс)
- Переключаться между разделами через боковое меню (Главная, Документы, Аналитика, Аккаунт, Выйти)

## 3. Страница «Документы» (файловое хранилище)

**Что можно делать:**
- Просматривать список файлов и папок
- Искать файлы через строку поиска
- Упорядочивать по названию, по дате изменения
- Создавать новые папки
- Загружать, скачивать, удалять, переименовывать, архивировать файлы
- Просматривать заметки, привязанные к документам
- Смотреть использование памяти (103 МБ / 2 ГБ)
- Переходить в корзину
- Открывать документы для просмотра и анализа
- Сортировать по папкам (Работа, OZON Банк, Документы, Контракты, Отчёты и т.д.)

## 4. Страница «Аналитика» (статистика и отчёты)

**Что можно делать:**
- Выбирать период, тип файлов, контрагента для фильтрации данных
- Просматривать общую статистику:
  - количество проверенных документов
  - качество документов (процент соответствия стандартам)
  - количество изученных контрагентов
  - количество выявленных рисков
  - процент отклонений
- Смотреть детализацию по папкам и контрагентам (название, количество документов, качество, риски, рейтинг)
- Принимать решение «Доверять» / «Не доверять» контрагенту
- Скачивать отчёт
- Управлять файлами и папками (аналогично разделу «Документы»)

## 5. Личный кабинет (Аккаунт)

**Что можно делать:**
- Редактировать общие настройки (язык, дата/время, масштаб интерфейса, всплывающие подсказки)
- Настраивать анализ и промпты:
  - режим анализа (расширенный)
  - генерацию рекомендаций, предложений текста, тепловую карту, цветовые метки (хорошо, сомнительно, риски)
  - вводить свой промпт для персонализации анализа
- Просматривать баланс и пополнять его
- Управлять подпиской: смотреть статус, количество проверок в день, дату следующего списания, изменить способ оплаты
- Просматривать историю платежей
- Управлять устройствами (список подключённых устройств)
- Настраивать архивацию старых документов
- Сбросить настройки, сохранить изменения
- Выйти из аккаунта

## 6. Общее для всех страниц

- Верхняя панель: логотип, выбор языка (RU), поиск, имя пользователя, уровень подписки (Продвинутая), количество оставшихся проверок (15)
- Боковое меню (или левая панель) для навигации между разделами
- Иконка «?» для помощи/обратной связи
