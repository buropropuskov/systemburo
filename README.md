# Системный анализ: комплект конспектов

Учебные материалы по профессии системного аналитика. Ветка независимая: своя история,
никакого кода, к разработке основного продукта отношения не имеет.

Исходники в `src/docs/*.md`, оттуда и правятся: PDF пересобирается, руками его не трогают.
Документы 01-06 разбирают предмет, 07 и 08 - выход на рынок труда.

## Пересборка

```
node src/build.mjs        # все документы
node src/build.mjs 04     # только тот, чей файл начинается с 04
```

Зависимости (`markdown-it`, `playwright`) в ветке не хранятся: скрипт берёт их из соседнего
чекаута либо из каталога, указанного переменной окружения.

```
ANALYST_NODE_MODULES=/путь/к/node_modules node src/build.mjs
```

Печать идёт через Chromium из Playwright, поэтому нужен установленный браузер
(`npx playwright install chromium`).

## Как добавить документ

1. Положить `src/docs/NN-имя.md`. Заголовки уровня `##` становятся разделами и начинаются
   с новой страницы, `###` вкладываются в них. Нумерация разделов и оглавление строятся сами.
2. Добавить запись в `src/docs/meta.json`: подпись над заголовком, название, аннотация.
3. Собрать и закоммитить `.md` вместе с `.pdf`.

## Резюме

Рабочие материалы отклика лежат отдельно от конспектов, в `resume/`.

| Файл | Назначение |
|---|---|
| `resume/resume.md` | Источник одностраничного резюме, из него собирается PDF |
| `resume/resume-hh.md` | Тот же текст, разложенный по полям формы hh.ru, с пояснениями что и почему |
| `resume/cover-letters.md` | Три шаблона сопроводительного письма: стажировка, продуктовая компания, банк |

Незаполненные места отмечены угловыми скобками `⟨…⟩` и подсвечиваются в PDF, чтобы
черновик нельзя было отправить по ошибке.

```
node src/build-resume.mjs
```

Контакты в исходнике не хранятся: ветка лежит в репозитории продукта, и телефон с
почтой оттуда уже не убрать. Чтобы собрать резюме с контактами, нужен файл
`resume/contacts.local.json`, который не коммитится:

```json
{
  "phone": "+7 ...",
  "email": "...",
  "telegram": "@...",
  "portfolio": "https://..."
}
```

Есть файл - собирается `pdf/resume-personal.pdf` (тоже вне git), нет файла -
`pdf/resume.pdf` с заглушками вместо контактов.
