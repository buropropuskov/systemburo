# Визуальная эстетика интерфейсов

Практическое задание 1: применение пяти принципов визуального дизайна -
масштаба, визуальной иерархии, баланса, контраста и гештальт-принципов.

Бриф 3: страница услуги «Разработка сайтов» в digital-агентстве.
Аудитория - владельцы малого и среднего бизнеса, цель страницы -
получить заявку.

## Состав

| Путь | Что это |
|---|---|
| `Практическая-1-5-принципов-визуального-дизайна.docx` / `.pdf` | пояснительная записка: дизайн-идея, разбор каждого принципа, сетка, типографическая шкала, палитра с проверкой контраста, расчёт шкалы процесса |
| `макеты/страница-услуги.html` | автономная страница макета, открывается в браузере без сервера |
| `макеты/страница-услуги.png` | скриншот макета целиком, 1440 x 4812 |
| `исходники-холста/` | артборд в формате холста: сетка-гайд 12 колонок и подписи к решениям на полях |

## Параметры макета

Холст 1440 x 4812. Сетка 12 колонок, боковые поля 120, желоб 24, ширина
колонки 78, шаг отступов 8. Четыре кегля: 72 / 36 / 20 / 16. Гарнитуры -
Manrope для содержания, IBM Plex Mono для служебного слоя.

Палитра: белый фон, графит #17191F для текста, серый #666C78 для
второстепенного, синий #4A57D8 на действиях и числах. Светло-серые
полосы #F7F8FA задают ритм секций.

Растровых изображений в макете нет: превью работ и превью в первом
экране собраны из блоков средствами вёрстки, каждое в палитре своей
отрасли. Страница отображается одинаково в любом окружении и не зависит
от загрузки картинок.

Шкала процесса работает как информационная графика: ширина полосы равна
доле этапа в общем сроке, сверху проставлена ось дней. Футер устроен как
колофон с названием студии, срезанным нижним краем макета.

Тексты, цены, имена и показатели условные.
