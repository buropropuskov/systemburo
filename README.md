# Визуальная эстетика интерфейсов

Практическое задание 1: применение пяти принципов визуального дизайна -
масштаба, визуальной иерархии, баланса, контраста и гештальт-принципов.

Бриф 3: страница услуги «Разработка сайтов» в digital-агентстве.
Аудитория - владельцы малого и среднего бизнеса, цель страницы -
получить заявку.

## Состав

| Путь | Что это |
|---|---|
| `Практическая-1-5-принципов-визуального-дизайна.docx` / `.pdf` | пояснительная записка: дизайн-идея, разбор каждого принципа по элементам, сетка, типографическая шкала, палитра с проверкой контраста |
| `макеты/страница-услуги.html` | автономная страница макета, открывается в браузере без сервера |
| `макеты/страница-услуги.png` | скриншот макета целиком, 1440 x 5008 |
| `исходники-холста/` | артборд в формате холста: сетка-гайд 12 колонок и подписи к принципам на полях |

## Параметры макета

Холст 1440 x 5008. Сетка 12 колонок, боковые поля 120, желоб 24, ширина
колонки 78, шаг отступов 8. Типографика ограничена четырьмя кеглями:
80 / 36 / 20 / 16. Гарнитуры - Manrope для содержания, IBM Plex Mono
для служебного слоя.

Палитра: графит #0D1117, тёмная поверхность #161B23, кремовый #F4F1EC,
акцент #CDFF4F. Акцентный цвет закреплён за действием и больше нигде
не заливает площадь.

Превью проектов собраны из блоков как миниатюры интерфейсов, каждое
в палитре своей отрасли. Тексты, цены и показатели условные.
