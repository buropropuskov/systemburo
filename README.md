# Визуальная эстетика интерфейсов

Практическое задание 1: применение пяти принципов визуального дизайна -
масштаба, визуальной иерархии, баланса, контраста и гештальт-принципов.

Взяты два брифа:

- бриф 1 - лендинг онлайн-марафона по йоге «21 день гармонии»;
- бриф 3 - страница услуги «Разработка сайтов» в digital-агентстве.

## Состав

| Путь | Что это |
|---|---|
| `Практическая-1-5-принципов-визуального-дизайна.docx` / `.pdf` | пояснительная записка: разбор каждого принципа по элементам, сетка, типографические шкалы, палитры с проверкой контраста |
| `макеты/*.html` | автономные страницы макетов, открываются в браузере без сервера |
| `макеты/*.png` | скриншоты макетов целиком, ширина 1440 px |
| `исходники-холста/` | артборды в формате холста: сетка-гайд 12 колонок и подписи к принципам на полях |

## Параметры макетов

Ширина 1440, 12 колонок, боковые поля 120, желоб 24, ширина колонки 78,
шаг отступов 8. Типографика ограничена четырьмя кеглями: 88 / 40 / 22 / 16
в лендинге и 72 / 36 / 20 / 16 на странице услуги.

Фотографии заменены рамками с указанием размера в пикселях, тексты,
цены и отзывы условные.
