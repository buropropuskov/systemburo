Аналитика — мокапы Фазы 0

Три направления страницы «Аналитика». Общий каркас одинаковый (вкладки Дашборд / Отчёты / Мониторинг, палитра и токены проекта) — различается поток конструктора отчётов (центральная часть по ТЗ). Открой каждый, покликай вкладки, выбери направление. По умолчанию открыта вкладка «Отчёты».

Вариант 1

Гид

Пошаговый мастер, дружелюбный к оператору, который не знает систему наизусть.

  • Слева — готовые наборы и мои шаблоны
  • Справа — степпер: что считаем → разрез → фильтры → период
  • Подсказки на каждом шаге, разумные дефолты
  • Максимальная обучаемость и «не страшно»

Вариант 2

Студия

Одноэкранная мощная панель в духе Metabase. Live-предпросмотр — герой.

  • Слева — поиск + аккордеоны разделов с метриками/фильтрами
  • Центр — мгновенный предпросмотр (таблица + график)
  • Справа — пресеты и мои шаблоны с индикатором «изменено»
  • Плотно и быстро для повторяющихся отчётов

Вариант 3

Галерея + фраза

Самый понятный: отчёт собирается как предложение естественным языком.

  • Сверху — галерея пресетов с мини-превью графиков
  • Конструктор-«фраза»: «Посчитать [X] по [Y] за [период] где [фильтр]»
  • Каждый chip — кликабельный дропдаун
  • Обучение на примерах, минимум порога входа
