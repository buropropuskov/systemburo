# ADR-001: Go вместо Rust

**Статус:** Принято (март 2026)

## Контекст

Бэкенд был написан на Rust (Actix-web, SQLx). При росте до 100+ эндпоинтов скорость разработки стала узким местом: SQLx macros требовали живую БД для компиляции, отсутствовал сервисный слой, бизнес-логика в handlers по 3800+ строк, нет тестов.

## Решение

Переписать бэкенд на Go (Echo v4, GORM). Сохранить совместимость со схемой БД — AutoMigrate детектирует существующие таблицы Rust-бэкенда и мигрирует только новые.

## Последствия

**Плюсы:**
- Скорость разработки выросла в 3-5 раз (Go выучивается за неделю, Rust — за месяцы)
- Сервисный слой, тесты, middleware добавлены за дни
- Порог входа для нового разработчика — 2-3 дня
- Бинарь 15MB Alpine-образ (vs ~130MB Debian + Rust)

**Минусы:**
- Потеряны compile-time SQL проверки (sqlx macros)
- Нет memory safety гарантий без GC (для REST API несущественно)
- Все SQL-ошибки ловятся только в runtime

**Риск, который не реализовался:** Производительность — для 200 req/min разницы между Go и Rust нет.
