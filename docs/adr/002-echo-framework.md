# ADR-002: Echo v4 как HTTP-фреймворк

**Статус:** Принято

## Контекст

Нужен HTTP-фреймворк для Go. Альтернативы: Gin (самый популярный), Fiber (самый быстрый, но на fasthttp), Chi (минималистичный роутер), стандартная библиотека net/http.

## Решение

Echo v4 — баланс между функциональностью и простотой.

## Последствия

**Плюсы:**
- Middleware-цепочки из коробки (6 глобальных + JWTAuth на группах)
- Группировка маршрутов (22 группы в router.go)
- Встроенный Bind/Validate для JSON-запросов
- CustomHTTPErrorHandler для единого формата ответов
- Интеграция со Swagger через echo-swagger

**Минусы:**
- Меньше community чем у Gin (но достаточно для любых задач)
- Привязка к фреймворку (middleware несовместимы с net/http напрямую)
