# ADR-009: pgAdmin вместо Adminer

**Статус:** Принято (dev only)

## Контекст

Нужен web-интерфейс для PostgreSQL в dev-окружении. Варианты: Adminer (лёгкий, multi-DB), pgAdmin (тяжёлый, PostgreSQL-native), DBeaver (desktop).

## Решение

pgAdmin 4 в docker-compose.yml (dev). Не включён в docker-compose.prod.yml.

## Последствия

**Плюсы:**
- PostgreSQL-специфичный — лучше поддержка схем, индексов, ролей
- Продвинутый SQL-редактор с планом выполнения
- Визуализация связей между 44+ таблицами
- Паттерн взят из проекта CFA (проверенный подход)

**Минусы:**
- Образ ~300MB (vs ~100MB Adminer)
- Медленнее стартует (10-15 сек)
- На production отсутствует (и не должен быть — прямой доступ к БД небезопасен)
