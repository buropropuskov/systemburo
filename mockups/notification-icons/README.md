# Иконка push-уведомления - варианты

Ветка-витрина, в `dev` не мержится. Открывать `index.html` - там примерка в макете уведомления,
переключение вариантов и сравнение с тем, что стоит сейчас.

## Откуда взяты варианты

Первый заход рисовался в отрыве от продукта (пропуск, бейдж, шлагбаум) и был отклонён - формы
ниоткуда не следовали. Эти выведены из знака в шапке приложения:

| Параметр | Значение | Откуда |
|---|---|---|
| Плашка | скругление 31% (10px при 32px) | `NavMenu.vue`, `.nav-logo` |
| Заливка | градиент 135°, `#3d49c7` -> `#4F5BDF` | `--accent-hover` -> `--accent` в `tokens.css` |
| Символ | контур, белый | `navIcons.js`, ключ `logo` |
| Толщина линии | 1.7 при сетке 24 | `NavIcon.vue` |

То есть в шторке телефона человек увидит ровно тот знак, который видит в шапке системы.

## Варианты

| Файл | Что это |
|---|---|
| `brand-icon.png` | знак приложения на градиентной плашке - точная копия шапки |
| `brand-icon-flat.png` | то же без градиента, плоская заливка `#4F5BDF` |
| `brand-bell.png` | колокольчик тем же контуром на той же плашке |
| `brand-badge.png` | значок строки состояния: контур знака, белый на прозрачном |
| `brand-badge-bell.png` | значок строки состояния с колокольчиком |

Крупная картинка 192x192, значок 96x96. Цвет значка не важен - телефон красит его сам.

## Что стоит сейчас

`current-icon.png` и `current-badge.png` - пирамида парка на оранжевой заливке. С интерфейсом
не перекликается: оранжевый в системе не используется нигде, кроме логотипа парка на входе.

## Как применить выбранный

Скопировать в `frontend/public/` под именами `notification-icon.png` и `notification-badge.png`.
Подключение в `frontend/public/sw.js` уже стоит, меняются только файлы.
