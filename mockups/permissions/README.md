# Мокапы — система прав доступа

Статичные макеты для выбора layout перед реализацией эпика по правам доступа.
Стиль — действующий дизайн systemburo (Montserrat, primary `#4F5BDF`, pill-кнопки, модалки 30px).
Это **не** рабочий код, только визуальные макеты.

## Как смотреть

Открыть `index.html` в браузере (двойной клик) — оттуда ссылки на все варианты.
Либо локальный сервер из корня репозитория:

```
python3 -m http.server 8099 --directory mockups
# затем http://127.0.0.1:8099/permissions/index.html
```

Быстрый просмотр без запуска — PNG в `screenshots/`.

## Варианты экрана настройки прав

| Файл | Описание |
|---|---|
| `access-two-columns.html` | **Рекомендуемый.** Слева источники (тумблер Администратор, Роль, Группы, Блокировка), справа дерево точечных прав с бейджем источника (роль / группа / лично). Источники и точечные права видны одновременно. |
| `access-single-scroll.html` | Роль и группы компактно сверху, ниже точечные права секциями, блокировка в конце. Один вертикальный скролл. |
| `access-tabs.html` | Текущий подход: вкладки «Роль и группы» + «Точечные права». Минимум переделки, но источники и точечные не видны вместе. |
| `banned-cabinet.html` | Заблокированный пользователь в Личном кабинете: полу-красный неснимаемый оверлей, причина блокировки, контакты Бюро пропусков, выход. |

## Что показано в макетах

- Тумблер **Администратор** (все права + точечные исключения).
- **Роль** (дропдаун, одна) и **Группы** (чипы, несколько).
- Точечные права по категориям из ТЗ: навигация, шапка, центр заявок, таблицы, сотрудники/автомобили, администрирование.
- Бейдж **источника** каждого права: от роли / от группы / личный override.
- Super-only пункты (Техработы) — заблокированы с замком.
- Секция **блокировки** с полем причины.
