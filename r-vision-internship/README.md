# Тетрадь тестировщика

Рабочая тетрадь для подготовки к стажировке QA: теория, практика с заготовками, тесты
для самопроверки и ответы на всё. Материал подобран по требованиям вакансии стажёра-тестировщика
(ручное тестирование с уклоном в автоматизацию) плюс общая база тестирования.

Все разделы работают на один сквозной проект: тест-набор для формы подачи заявки, который
к концу тетради собирается в отдельный репозиторий с Page Object, фикстурами и автотестами.

## Файлы

- `tetrad-qa-rvision.pdf` — готовая тетрадь, 49 страниц A4, для чтения и печати
- `workbook.html` — исходник, из которого собирается PDF

## Пересборка PDF

Нужен установленный Playwright (есть в `frontend/`):

```
node - <<'JS'
import { chromium } from '@playwright/test';
const dir = process.cwd();
const b = await chromium.launch();
const p = await b.newPage();
await p.goto('file://' + dir + '/workbook.html', { waitUntil: 'networkidle' });
await p.emulateMedia({ media: 'print' });
await p.pdf({ path: dir + '/tetrad-qa-rvision.pdf', format: 'A4', printBackground: true,
  margin: { top: '14mm', bottom: '16mm', left: '15mm', right: '15mm' } });
await b.close();
JS
```

## Печать

49 страниц, то есть 25 листов при двусторонней печати. Схемы и таблицы читаются в чёрно-белом
режиме: цвет используется только как акцент. Блоки заметок, трекер прогресса, словарь терминов
и журнал прогонов рассчитаны на заполнение от руки.
