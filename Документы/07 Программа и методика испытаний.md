# Программа и методика испытаний

Документ устанавливает состав, порядок и критерии проверок системы бюро пропусков
в ходе пилотной эксплуатации. По результатам проверок оформляется протокол приёмки.

Поля в угловых скобках заполняются при проведении.

## 1. Объект испытаний

Система бюро пропусков, развёрнутая на сервере оператора, версия <номер версии,
идентификатор сборки>. Проверке подлежит система целиком: серверная часть, интерфейс,
база данных, средства обслуживания.

## 2. Цель

Подтвердить, что система выполняет заявленные функции на оборудовании и в сети
оператора, что данные защищены заявленными средствами и что порядок обслуживания
воспроизводим силами оператора.

## 3. Условия проведения

| Условие | Значение |
|---|---|
| Место | Сервер оператора, <адрес системы> |
| Период | С <дата> по <дата> |
| Данные | Реальные заявки и участники |
| Участники со стороны оператора | <ФИО, роли> |
| Участник со стороны исполнителя | <ФИО> |

Для проверок заводятся учётные записи всех ролей: заявитель, согласующий,
принимающий, охранник поста, администратор.

## 4. Порядок проведения

Проверки выполняются по порядку разделов. Каждая проверка выполняется на рабочей
системе действиями через интерфейс, если в методике не сказано иное. Результат
записывается в таблицу протокола: выполнено, выполнено с замечанием, не выполнено.
Замечание описывается словами, с указанием шагов воспроизведения.

Проверка, затрагивающая необратимые действия над реальными данными, выполняется
на данных, заведённых для испытаний.

## 6. Критерии приёмки

Испытания считаются успешными при одновременном выполнении условий:

1. Все проверки разделов 5.1, 5.4 и 5.9 выполнены без замечаний. Это доступность,
   основной сценарий работы и защита данных.
2. В остальных разделах доля проверок с отметкой «не выполнено» равна нулю,
   а замечания устранены либо согласованы сторонами как несущественные с указанием
   срока устранения.
3. За период испытаний не зафиксировано: утраты данных, недоступности системы более
   <допустимое время> подряд, несанкционированного доступа.
4. Показатели пилотной эксплуатации, установленные документом о критериях завершения
   пилотного периода, достигнуты.

## 8. Порядок работы с замечаниями

Замечание фиксируется с шагами воспроизведения. Исполнитель устраняет его и сообщает
о готовности к повторной проверке. Повторная проверка выполняется по той же методике,
её результат записывается отдельной строкой с пометкой о повторе.
